Data & backup

—

This is a static, no-backend app — everything (workbooks, filters, chat history, preferences) is saved in this browser's local storage, not on a server. Use the points below to keep your data safe.

  • Auto-save — every change in Data Studio and Settings is saved to local storage the moment you make it. No "Save" button needed day-to-day.
  • Backup file — export everything to one JSON file you can store safely or move to another browser/device.
  • Restore — import a previously exported backup file to bring your data back.
  • Per-browser scope — data does not sync across browsers/devices on its own; export/import is how you move it.
  • Real database (optional) — connect Odoo below to keep orders/products in a real backend instead of local storage only.

AI Assistant API

—

The AI Assistant runs a local offline engine by default. To have it call a real model instead, add your key to one dedicated file: js/ai-api-config.js — nothing else needs editing.

  • Open js/ai-api-config.js and paste your key into apiKey.
  • Leave it blank to keep the free, offline demo engine — nothing breaks either way.
  • The key is only ever read from that file, in your browser — never sent anywhere but the model API you configure.
